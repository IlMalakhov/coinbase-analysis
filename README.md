# Coinbase Company Analysis — Graphs & Visualizations

## Overview

Main illistrations are on:

- Coinbase's historical timeline and product expansion
- The "Coinbase Effect" on asset prices
- Revenue model

## Contents

| Folder/File   | Description                                 |
| ------------- | ------------------------------------------- |
| `/scripts`    | All .py files                               |
| `/output`     | PNG exports of key graphs                   |
| `/regulation` | PNG exports of regulations Mermaid diagrams |
| `README.md`   | This file                                   |

## Tools Used

- `Python libs`
  - `Plotly` for main data visualizations
  - `Matplotlib` for prototyping graphs
  - `Seaborn`
  - `Yahoo Finance` for getting stocks data
- `Mermaid.js` for regulation diagrams
